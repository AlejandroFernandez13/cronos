CRONOS — Modo clásico (audio-only v2)

Esta versión mejora la claridad de los turnos y la colocación:
- Flujo visual 1 Escuchar -> 2 Colocar -> 3 Resultado -> 4 Bonus.
- Banner grande indica claramente quién juega.
- La línea temporal tiene ranuras grandes y pulsables.
- Cada ranura indica ANTES, ENTRE AÑOS o DESPUÉS.
- Al pulsar una ranura se muestra una confirmación "Colocar aquí".
- Audio sin reproductor de vídeo ni metadatos visibles.

Para desplegar: subir estos archivos a GitHub y volver a desplegar en Render.
